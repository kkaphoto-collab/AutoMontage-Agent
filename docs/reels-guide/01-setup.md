# Модуль 1. Рабочее место

**Цель модуля:** на вашем компьютере стоит движок монтажа, открывается «Пульт роликов», и,
если вы выбрали путь «аватар», подключены HeyGen и ваш голос.

**Время:** один раз, 30–60 минут. Большую часть установки делает агент.

**До начала:** установлен Claude Code или Codex, у вас есть подписка. Claude Code бывает приложением
для Mac и Windows, расширением для редактора VS Code и программой для терминала – новичку проще всего
приложение или VS Code. Как установить, написано на сайтах этих программ.

---

## Шаг 0. Азбука: терминал, агент и файлы

Пять вещей, которые понадобятся во всех модулях.

**Терминал** – окно, куда вводят команды текстом. На Mac: нажмите `Cmd + Пробел`, наберите
«Терминал» и нажмите Enter. На Windows: «Пуск» → PowerShell. Команду из курса вставьте в окно и
нажмите Enter. Если Mac спросит пароль, символы при вводе не видны – это нормально, наберите
его и нажмите Enter.

**Открыть агента в папке.** Агент работает с той папкой, в которой его открыли:

- в приложении Claude Code или Codex – выберите папку при открытии проекта;
- в VS Code – «Файл» → «Открыть папку», затем панель Claude Code или Codex.

**Разрешения.** Перед командами агент спрашивает разрешение. Установку и проверки разрешайте.
Если он просит удалить файлы, отправить что-то в интернет или потратить деньги – прочитайте,
что именно, и смело отказывайте, если не уверены.

**Как дать агенту файл или папку.** Перетащите файл из Finder или Проводника прямо в окно чата –
вставится путь к нему. Удобно держать всё в одной папке:

```text
Монтаж/
  AutoMontage-Agent/        движок, появится после шага 1
  Исходники/                ваши видео с телефона
  Музыка для роликов/       шаг 5
```

**Долгая работа.** Сборка роликов занимает от минут до пары часов. Держите ноутбук на зарядке и не
закрывайте крышку. Если агент остановился из-за лимита подписки, ничего не пропало: всё лежит в
файлах. Когда лимит обновится, напишите «продолжи». Вернуться на следующий день можно в тот же чат
или в новый, открытый в папке движка: вставьте фразу из пульта, и агент продолжит по файлам ролика.

## Шаг 1. Установите движок

**Что вы делаете.** Создайте папку «Монтаж», откройте в ней агента (шаг 0) и вставьте фразу:

> Установи движок автомонтажа из репозитория https://github.com/mcdenil-skills/AutoMontage-Agent.
> Склонируй его, поставь зависимости (npm ci и Python-пакеты из requirements.txt) и глобальную
> команду automontage (npm install -g .). Проверь окружение командой automontage doctor, затем
> собери демо командой npm run demo. Скажи, чего не хватает, и помоги это поставить.

**Что делает агент.** Скачивает движок, ставит Node.js-пакеты, локальную расшифровку речи
(faster-whisper) и проверяет, что на компьютере есть `ffmpeg` – программа, которая склеивает
и кодирует видео. Если чего-то не хватает, агент подскажет, что поставить.

На Mac при первом скачивании может появиться окно «Установить инструменты разработчика» –
нажмите «Установить» и дождитесь конца.

**Что вы увидите.** Отчёт `doctor` без красных строк и файл `out/demo.mp4` – короткое тестовое
видео. Если демо собралось, движок работает.

> **Важно.** Движок появился в папке `Монтаж/AutoMontage-Agent`. Закройте агента и откройте его
> заново **уже в этой папке**. Дальше всегда работайте только здесь: в папке движка лежат правила
> агента – как монтировать, как работать с пультом, что нельзя делать без вашего согласия.

---

## Шаг 2. Проверьте расшифровку речи

**Что вы делаете.** Скажите агенту:

> Проверь, что локальная расшифровка Whisper работает, на любом коротком видео с речью.

При первом запуске скачается модель распознавания, это разовая загрузка. Дальше речь
расшифровывается прямо на вашем компьютере без интернета и без платных ключей.

---

## Шаг 3. Значок пульта

**Что вы делаете.** Скажите агенту «создай значок пульта» или выполните сами:

```bash
automontage pult --install-shortcut
```

- **macOS:** значок «Пульт роликов» появится в папке «Программы» вашей домашней папки.
  Перетащите его в Dock.
- **Windows:** значок появится на рабочем столе.

Откройте пульт двойным щелчком. Пока роликов нет, он пустой – это нормально.

Значок запоминает, где стоит Node.js, а на macOS ещё и `ffmpeg`. Переустановили их – создайте значок заново той
же командой. Подробнее – в [инструкции к пульту](../PULT.md).

## Шаг 4. Путь «аватар»: HeyGen и ваш голос

Пропустите этот шаг, если будете снимать себя на телефон ([модуль 3](03-source-video.md)).

> **Внимание.** Навык аватара работает на macOS и Linux. На Windows выбирайте путь «своя
> съёмка».

**Что понадобится.**

- **HeyGen** с подпиской и кредитами. В нём нужен ваш цифровой двойник (Digital Twin) – аватар,
  снятый с вас на видео. Его можно создать на сайте HeyGen или попросить агента после установки
  навыка.
- **ElevenLabs** с клоном вашего голоса – если хотите, чтобы аватар говорил по тексту вашим
  голосом. Без ElevenLabs можно записать голос на диктофон: аватар повторит его губами.

**Что вы делаете.**

1. Установите официальную программу HeyGen и войдите в свой аккаунт. Это программа для
   терминала: в Launchpad её не будет. Выполните команды сами, по одной:

   ```bash
   curl -fsSL https://static.heygen.ai/cli/install.sh | bash
   heygen auth login
   ```

   Вторая команда откроет браузер – войдите в свой аккаунт HeyGen. Если терминал ответил
   `command not found`, закройте окно терминала, откройте новое и повторите вторую команду.

2. Попросите агента установить навык аватара:

   > Установи навык https://github.com/mcdenil-skills/heygen-avatar-oauth для Claude Code
   > (или Codex) по его README и проверь его командой doctor.

3. Для озвучки по тексту нужны ключ ElevenLabs и код вашего голоса. Ключ создаётся на сайте
   ElevenLabs в разделе API Keys. Код голоса (Voice ID) – строка из букв и цифр у вашего клона
   в разделе голосов. Попросите агента:

   > Создай файл для ключей ElevenLabs и открой его мне в текстовом редакторе.

   Вставьте значения своими руками, сохраните и закройте. В чат ключи **не присылайте**.

   ```dotenv
   ELEVENLABS_API=ваш_ключ
   ELEVENLABS_VOICE_ID=код_вашего_голоса
   ```

**Проверьте себя.** Проверка навыка показывает `ok: true` и `billingType: subscription`. Это
значит, что ролики будут оплачиваться кредитами вашей подписки HeyGen, а не отдельным
API-кошельком. Если вместо `subscription` написано другое, роликов не запускайте и покажите ответ
агенту: скорее всего, вход выполнен не в тот аккаунт.

## Шаг 5. Музыка

В движке нет музыки: у каждого трека своя лицензия. Соберите свою библиотеку один раз.

**Что вы делаете.** Скачайте 15–20 инструментальных треков без вокала в одну папку, например
`Музыка для роликов`. Мы брали [StreamBeats](https://www.streambeats.com/): по их лицензии треки
можно ставить в монетизированные ролики без указания автора. Перед публикацией проверьте
актуальные условия на сайте. Подойдёт и любая другая музыка, на которую у вас есть права.

Зачем 15–20 треков: у каждого ролика своя музыка, даже у вариантов для Instagram и YouTube одной темы.
Одинаковая музыка в ленте надоедает зрителю.

## Шаг 6. Сток по желанию

Бесплатный ключ [Pexels](https://www.pexels.com/api/) даёт агенту искать стоковые видео по смыслу
фразы. Без ключа монтаж тоже работает, но сток придётся приносить самим.

**Что вы делаете.** Получите ключ на сайте Pexels и попросите агента:

> Подскажи, куда положить PEXELS_API_KEY в файл .env движка.

Ключ вставьте в файл сами. В чат не присылайте.

## Проверьте себя

- [ ] `automontage doctor` без красных строк, `npm run demo` собрал тестовое видео.
- [ ] Пульт открывается двойным щелчком по значку.
- [ ] Для аватара: проверка навыка HeyGen показывает `ok: true`.
- [ ] Есть папка с музыкой, на которую у вас есть права.
- [ ] Агент открыт в папке движка.

## Грабли

| Что случилось | Как избежать |
|---|---|
| `doctor` предупреждает про WebP: фото не открываются, видео работает | Попросите агента: «Поставь полную сборку ffmpeg с поддержкой WebP». Подробности – в [README](../../README.md) |
| Значок пульта перестал запускаться | После обновления Node.js создайте значок заново: `automontage pult --install-shortcut` |
| Агент просит прислать ключ в чат | Не присылайте. Ключ всегда вставляете вы сами в локальный файл |
| Агент открыт не в папке движка и «не знает» пульт | Откройте Claude Code или Codex в папке `AutoMontage-Agent` |
